# Asset provenance

Original procedural geometry generated for this GlucoTwin prototype. No external meshes or textures.

Editable source: `tools/generate_imported_anatomy.py` in the project root. Dependencies: NumPy, scikit-image, SciPy and trimesh. Smooth anatomy surfaces use signed-distance fields and marching cubes; bowel geometry follows an original continuous three-dimensional spline.

Educational schematic; not anatomically expert-reviewed, clinically validated, or patient-specific. Scientific relationships still require expert review.
